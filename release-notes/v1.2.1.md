## What's new in 1.2.1: MusTra has a logo

MusTra now has its own icon: a **canary pick**, a yellow plectrum-shaped canary on a purple tile, with the **M** as its wing and the **T** as its perch.

- **Windows:** `MusTra-windows.exe` shows the logo in Explorer, on the taskbar and in the window title bar.
- **macOS:** `MusTra.app` shows it in Finder and the Dock.
- **Linux:** the window and taskbar show it.
- The **welcome page** shows it next to the MusTra title.

This is a temporary logo; the final one is coming in a later version. Nothing else changed since 1.2.0: same dromoi, makams, maqamat, tips and song suggestions.

### Downloads

| System | File | First launch |
|---|---|---|
| Windows | `MusTra-windows.exe` | If SmartScreen warns: *More info → Run anyway* |
| macOS | `MusTra-macos.zip` | Unzip, then right-click the app → *Open* |
| Linux | `MusTra-linux` | `chmod +x MusTra-linux` |

No installation and no Python needed. Your song suggestions and corrections from earlier versions are kept.
